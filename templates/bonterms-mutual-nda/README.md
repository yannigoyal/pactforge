# Bonterms Mutual NDA

A balanced, enterprise-ready Mutual Non-Disclosure Agreement drafted by the
[Bonterms Standard Agreement Committee](https://bonterms.com/committee/).

- **Template file:** [`Mutual-NDA.md`](./Mutual-NDA.md)
- **License:** [CC BY 4.0](./LICENSE.md)
- **Source:** [Bonterms/Mutual-NDA](https://github.com/Bonterms/Mutual-NDA) (imported as-is, unmodified)

## Usage

This NDA is designed to be used together with a signed Cover Page that identifies the
parties and key terms (Effective Date, Term of NDA, Confidentiality Period, Governing Law
and Courts). See the [Bonterms Mutual NDA repository](https://github.com/Bonterms/Mutual-NDA)
for an example Cover Page and additional guidance.
